# Password Generator

A simple password generator built using HTML, CSS and JavaScript.
Never use an insecure password again.

**Live Website:** https://password-generator-om-tandon.vercel.app/

---

## About

This project was made while learning JavaScript and is inspired by the Password Generator project from Scrimba's JavaScript course.

---

## Features

* Generate random passwords
* Customizable password length
* Uppercase letters
* Lowercase letters
* Numbers
* Special characters
* Copy generated passwords
* Responsive interface

---

## Getting Started

### Clone the repository

```bash
git clone https://github.com/om-tandon/Password-Generator.git
```

### Navigate to the project

```bash
cd Password-Generator
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The terminal will provide a local URL where you can open the website.
